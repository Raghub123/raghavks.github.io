# Raghav KS Portfolio V2

A premium, light/vibrant static portfolio for GitHub Pages.

## Files

- `index.html` — complete homepage
- `assets/styles.css` — premium responsive styling
- `assets/script.js` — mobile navigation + scroll reveal
- `assets/profile-image.png` — supplied professional photo
- `assets/Raghav_KS_Data_Solution_Architect.pdf` — supplied resume
- `_config.yml` — Jekyll/GitHub Pages configuration

## Deploy

Replace the files in your existing `raghavks.github.io` repository with these files and push/commit.

GitHub Pages supports static HTML/CSS/JavaScript and Jekyll. PHP is not supported by GitHub Pages, so the old `contact.php` is intentionally not included.

## Personal links to update

1. Replace the LeetCode placeholder in `index.html`.
2. Replace the Substack placeholder in `index.html`.
3. If your GitHub username/link is different, update the GitHub links.
4. When you have actual project repositories, replace/add the project links.

## Contact

The contact CTA uses `mailto:` so it works on a static GitHub Pages site without a server-side backend.
